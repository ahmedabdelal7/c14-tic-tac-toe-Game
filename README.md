## 📌 Description
A classic Tic Tac Toe game built with C# Windows Forms where two players take turns marking cells on a 3x3 grid.

The game detects wins, draws, and manages turns dynamically, providing a simple and interactive user experience.

## ⚙️ Features
- Two-player gameplay
- Turn indicator (Player 1 / Player 2)
- Win detection (rows, columns, diagonals)
- Draw detection
- Game status display (In Progress / Winner)
- Restart game functionality

## 🏗️ How the System Works
1. The game starts with Player 1.
2. Players take turns clicking on grid cells.
3. Each move updates the board (X or O).
4. After every move:
   - The system checks for a winner.
   - If no winner, checks for draw.
5. The game displays:
   - Current turn
   - Game status
6. The player can restart the game at any time.
